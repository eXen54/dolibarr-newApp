Pourquoi c'est faisable en 1h par un dev intermédiaire
Zéro nouveau backend : getEmployees(), getHolidays(), et les salaires existent déjà comme services.
Le calcul est de l'arithmétique de dates pure côté client (compter les jours ouvrés d'un mois, retirer les fériés).
Les patterns UI (tableau, filtres, override par modal, totaux) sont copiables depuis GenerateSalaries.jsx et Holidays.jsx.
Une seule nouvelle route à ajouter dans App.jsx + une entrée de menu.

Cœur métier (le seul vrai code à écrire)

jours_ouvrés = joursOuvrables(mois) − fériésDuMois(holidays)
heures_mois  = weeklyhours / 5 × jours_ouvrés     // hebdo → journalier
salaire_dû   = heures_mois × taux_horaire
écart        = salaire_dû − déjà_payé
